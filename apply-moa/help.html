설치 및 사용 설명

사람인과 잡코리아 공고를 모으고, 선택한 기업에 등록 이력서로 지원합니다.

도우미 화면으로 돌아가기 →
설치·업데이트검색 조건이력·공고 수집일괄 지원결과 확인

1. 설치·업데이트

  1. 버전이 표시된 설치 파일을 실행하고 설치할 폴더를 선택합니다.
  2. 처음 설치할 때는 크롬 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 눌러 설치 폴더를 선택합니다.
  4. 업데이트할 때는 기존에 등록한 폴더에 설치한 뒤 확장 프로그램의 새로고침 버튼을 누릅니다. 열려 있는 도우미 페이지도 새로고침합니다.

기존 폴더에 업데이트하면 설정과 지원 기록을 유지할 수 있습니다. 새 폴더로 설치하면 별도 확장 프로그램으로 등록될 수 있습니다.

2. 검색 조건 설정

사이트 검색어
사이트에서 실제로 검색할 단어입니다. 여러 단어는 쉼표 또는 줄바꿈으로 구분합니다.
도우미 제목 검색어
수집한 공고 제목에 입력한 단어가 하나라도 있어야 지원 대상이 됩니다. 비우면 제목 포함 조건을 적용하지 않습니다.
제외 기업 목록
지원 대상에서 제외할 기업명을 입력합니다. 쉼표 또는 줄바꿈으로 구분합니다.
제목 제외 단어
제목에 입력한 단어가 하나라도 있으면 제외합니다. 대소문자를 구분하지 않으며 본문은 검사하지 않습니다.
기업 형태·채용 형태·희망 지역
제목을 눌러 펼치거나 접습니다. 접으면 선택한 조건을 요약해 보여 줍니다. 상세 지역은 시·군·구 단위로 선택할 수 있습니다.
동시 지원 개수
1~5개 중 선택합니다. 1개는 순차 지원이며, 2개 이상은 공고별로 동시에 처리합니다. 자동지원이 켜져 있을 때 적용됩니다.
공고 사이 대기
각 지원 작업이 다음 공고를 시작하기 전 기다리는 시간입니다.

설정 저장을 눌러 적용합니다. 제목 검색어·제외 기업·제목 제외 단어는 기존 목록에 바로 반영됩니다. 사이트 검색어·기업 형태·채용 형태를 바꾸면 공고를 다시 수집합니다.

3. 지원 이력과 공고 수집

  1. 사람인과 잡코리아에 로그인하고 제출할 이력서를 각 사이트에 등록합니다.
  2. 두 사이트 이력 동시 수집을 누르거나 각 사이트의 지원 이력 수집을 누릅니다. 최근 2개월을 조회하고 마지막 페이지까지 수집합니다.
  3. 수집한 조회기간과 건수를 확인한 뒤 조회기간과 수집 건수를 확인했습니다를 체크합니다.
  4. 두 사이트 공고 수집을 누릅니다. 사람인과 잡코리아는 별도 작업으로 동시에 수집됩니다.

사람인은 100개씩, 잡코리아는 최대 5페이지를 함께 읽습니다. 공고 페이지는 시도당 5초를 기다리고 일시적인 로딩·연결 실패 시 최대 2회 재시도합니다. 중간에 실패하면 사이트별 이어서 수집을 사용할 수 있습니다.

등록일은 검색 결과에 표시된 날짜를 읽습니다. 표시되지 않는 공고와 날짜를 수집하기 전의 기존 공고는 —로 나타납니다.

4. 목록 확인 후 일괄 지원

  1. 회사·공고 제목·지역·등록일·지원 상태를 확인합니다.
  2. 지원할 공고를 체크합니다. 같은 기업의 여러 공고는 드롭다운에서 바꿀 수 있지만 하나만 선택할 수 있습니다.
  3. 자동으로 제출하려면 자동지원 사용을 켭니다. 끄면 지원 화면을 열고 직접 제출합니다.
  4. 자동지원이 켜져 있으면 이력서 제출 확인란에 체크한 뒤 선택 공고 일괄 지원을 누릅니다.

잡코리아에서 포트폴리오가 필수이면 첨부파일의 변경을 열고 첫 번째 등록 파일을 선택한 뒤 변경하기로 적용합니다. 적용된 파일을 확인하고 지원하기로 제출합니다. 동시 지원에서는 공고별 진행 상태를 표시합니다. 추가 입력이 필요한 공고는 직접 확인으로 남겨 두고 다른 공고를 계속 진행합니다. 같은 기업은 두 사이트에서도 한 공고만 지원 대상으로 처리합니다.

하단 처리 창은 접기·펼치기 버튼으로 크기를 줄일 수 있습니다. 접어도 진행 상태와 중지 버튼은 표시됩니다. 진행 중에는 도우미 페이지와 크롬을 열어 두세요. 중지를 누르면 다음 작업을 멈춥니다. 이미 제출된 지원은 취소하지 않습니다.

5. 결과 확인과 다시 시작

지원 완료
사이트 완료 표시 또는 지원 이력에서 완료를 확인한 상태입니다. 해당 잡코리아 지원 결과 창에서 회색 추가지원 버튼이 나타나는 경우도 완료로 인식합니다. 추가지원 버튼은 누르지 않습니다.
직접 확인
추가 입력·이력서 선택 등 확인이 필요한 상태입니다. 사이트에서 확인한 뒤 목록의 다시 선택 기능을 사용할 수 있습니다.
결과 불명·결과 확인 중
제출했지만 완료를 확정하지 못한 상태입니다. 완료 재확인 또는 지원 이력 수집으로 확인합니다. 자동 재제출하지 않습니다.
지원 이력 다시 수집 버튼 비활성화
해당 사이트의 이력 수집, 공고 수집 또는 지원 작업이 진행 중이면 비활성화됩니다. 한 사이트의 이력을 수집하는 동안 다른 사이트의 이력 수집은 시작할 수 있습니다. 작업을 마치거나 중지한 뒤 사용합니다.
이번 작업 집계 초기화
이번 작업 완료 건수의 기준과 선택 상태를 초기화합니다. 지원 이력·완료 기록·기업 중복 차단 기록은 유지합니다.

결과와 지원 이력은 화면의 저장 버튼으로 내보낼 수 있습니다.
