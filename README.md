# 채용지원모아 · ApplyMoa

사람인과 잡코리아 공고를 모으고, 설정한 조건에 맞는 기업에 등록 이력서로 지원하는 로컬 크롬 확장 프로그램입니다.

현재 버전: **0.1.70**

## 다운로드

- [Windows 설치·업데이트 파일](https://raw.githubusercontent.com/qqhrqqhr2/ApplyMoa/master/dist/ApplyMoa-Setup-0.1.70.cmd)
- [크롬 확장 프로그램 ZIP](https://raw.githubusercontent.com/qqhrqqhr2/ApplyMoa/master/dist/ApplyMoa-0.1.70.zip)

## 설치와 업데이트

1. 설치 파일을 실행하고 설치할 폴더를 선택합니다.
2. 크롬의 `chrome://extensions`에서 개발자 모드를 켭니다.
3. ‘압축해제된 확장 프로그램을 로드합니다’를 눌러 설치된 `apply-moa` 폴더를 선택합니다.
4. 업데이트는 기존에 크롬에 등록한 폴더에 설치한 뒤 확장 프로그램과 도우미 페이지를 새로고침합니다.

소스로 설치할 때는 이 저장소를 내려받아 `apply-moa` 폴더를 크롬에 등록하세요.

## 사용 순서

1. 사람인과 잡코리아에 로그인하고 이력서를 등록합니다.
2. 사이트 검색어와 도우미 제목 검색어, 제외 기업·단어, 기업·채용 형태, 희망 지역을 설정하고 저장합니다.
3. 지원 이력을 수집하고 조회기간·건수를 확인합니다. 두 사이트 동시 수집을 지원합니다.
4. 공고를 모아 지원할 기업을 선택합니다.
5. 자동지원 여부와 동시 지원 개수(1~5개)를 설정한 뒤 선택 공고를 일괄 지원합니다.

같은 기업은 두 사이트를 합쳐 한 공고만 선택할 수 있습니다. 제출 결과가 불명확한 공고는 자동으로 다시 제출하지 않으며 지원 이력으로 확인합니다. 잡코리아에서 포트폴리오가 필수이면 첫 번째 등록 파일을 선택해 적용합니다.

[상세 설치·사용 설명](apply-moa/help.html) · [변경 사항](CHANGELOG.md)

## 구성

- `apply-moa/`: 확장 프로그램 소스와 아이콘
- `dist/`: 버전이 표시된 설치 파일과 배포 ZIP

이력서·비밀번호·수집된 개인 지원 기록은 저장소에 포함하지 않습니다. 설정과 지원 기록은 사용자의 크롬에 저장됩니다. 유료 AI API 키는 필요하지 않습니다.
